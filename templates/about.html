🤖 AI Business Intelligence Dashboard

AI Business Intelligence Dashboard is an end-to-end Business Analytics platform that enables users to upload datasets, perform data preprocessing, generate interactive visualizations, build Machine Learning models, make predictions, generate AI insights, and download business reports—all from a single web application.

🚀 Project Features

  • 📂 Upload CSV & Excel Datasets
  • 📊 Interactive Analytics Dashboard
  • 🧹 Data Cleaning & Preprocessing
  • 🔄 Missing Value Handling
  • 📝 Rename Dataset Columns
  • 🔢 Encode Categorical Variables
  • 📈 Interactive Plotly Visualizations
  • 🤖 AI Generated Dataset Insights
  • 🧠 AutoML (Regression & Classification)
  • ⭐ Automatic Best Model Selection
  • 📌 Feature Importance Analysis
  • 🎯 Prediction Module
  • 📄 Download Cleaned Dataset
  • 📑 Download Prediction Results
  • 📈 Sales Forecasting Module
  • 📋 Business Intelligence Reports
